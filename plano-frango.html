Tecnologia

Stack — tudo grátis

Nada de Rust nem servidor Node próprio. É TypeScript do começo ao fim, e o Supabase faz o papel de backend.

CamadaEscolhaPor quêCusto
AppReact + Vite + TypeScriptRápido, enorme ecossistema, roda igual em Android e iOS.R$ 0
PWAvite-plugin-pwaManifest, ícone, offline e instalação na tela inicial sem configuração manual.R$ 0
VisualTailwind + MotionAnimações fluidas de verdade (transições, gestos, mola). É aqui que o app fica "foda".R$ 0
Login, banco, fotosSupabasePostgres + auth + storage + realtime num lugar só. Regras de acesso direto no banco (RLS).R$ 0
HospedagemCloudflare PagesBanda ilimitada no plano grátis, HTTPS, deploy a cada push no GitHub.R$ 0
PoseMediaPipe Pose LandmarkerRoda no celular, sem servidor e sem custo.R$ 0
NotificaçõesWeb Push + Supabase Edge Function + pg_cronLembrete de segunda e cobrança. No iPhone só funciona com o app instalado.R$ 0
VídeoCanvas + MediaRecorder (WebCodecs de reserva)O vídeo é montado no próprio celular, sem servidor de render.R$ 0

Por que não Firebase: desde 2024 o Storage do Firebase exige o plano pago Blaze (com cartão). O Supabase dá 1 GB de arquivo sem cartão.

Conta do armazenamento
2 pessoas × 3 ângulos × 52 semanas=312fotos/ano × ~250 KB (WebP 1080 px)≈78 MB/ano de 1 GB

A foto é comprimida no celular antes de subir. Banco de dados (peso, notas, treinos) fica em poucos MB.

Riscos e como contornar
Câmera no PWA do iPhone

Há relatos de câmera travando ou foto girada no modo tela inicial. Plano B: abrir a câmera nativa (<input capture>) e alinhar depois com o fantasma na tela de ajuste. Testar no dia 1.

Supabase pausa projeto parado 1 semana

Vocês vão usar toda semana, mas por garantia um GitHub Actions grátis faz um "ping" diário no banco.

Push no iPhone

Só depois de "Adicionar à Tela de Início" (iOS 16.4+). O app mostra um passo a passo na primeira abertura.

Gerar vídeo no Safari

MediaRecorder no Safari tem diferenças. Reserva: WebCodecs + muxer de MP4, ou GIF animado.

Foto com luz diferente

O app mede o brilho na câmera e avisa "tá escuro". Combinar o mesmo lugar e horário ajuda mais que qualquer código.

0 · Design

Identidade, paleta, tipografia e as telas no papel antes de codar. Próximo passo.

PWA mínimo só com câmera + silhueta, instalado nos dois celulares. Se passar, segue.

2 · Base

Login dos dois, check-in (peso, treinos, nota, fotos), feed com comentário e reação.

3 · Câmera-guia completa

Fantasma, pose detectada, contagem, vários ângulos, aviso de luz.

4 · Números

Gráfico de peso com tendência, calendário, sequência, medidas.

5 · Notificações

Lembrete de segunda e cobrança.

6 · Timelapse e resumos

Fotos alinhadas viram vídeo liso com o peso na tela. Resumo mensal.
